Data Structures Architecture Inspector

Live memory pointer topology backing Tumble Tower state.

1. Tower State — Singly Linked List (Head = Top Level) Prepend O(1) • Traversal O(N)

Each node represents one 3-block level. When the top level is filled, a new LevelNode is prepended as head in O(1).

2. Turn Queue — FIFO Queue Enqueue O(1) • Dequeue O(1)

Players rotate turns via standard FIFO queue: active player is dequeued from Front, makes their move, and is re-enqueued at Rear.

3. Move History — LIFO Stack Push O(1) • Pop O(1) Undo

Every confirmed block placement is pushed onto the stack. Undo pops the top record, reverses the block coordinates, and restores the turn queue order.

4. Auxiliary Stack — Extraction Pattern CS Traversal Pattern

To extract a block from level K in a singly linked list without random access: levels above K are pushed onto this auxiliary stack, the target block is extracted, and levels are popped back onto the tower in identical order.
